## 🗣 什麼是伯洋體？

**伯洋體**，源自 2026 台北市長選舉期間，網友對候選人沈伯洋發言風格的一種調侃標籤。

其核心特徵為：**只講美好目標，不講具體做法**，常搭配抽象術語與層層遞進的因果串聯，從一個小到不能再小的名詞一路推導到民主、文明、國際接軌，最後用一句「就是那麼簡單的道理而已」輕描淡寫收尾。

每一環聽起來都很有道理，合起來資訊量趨近於零。這個落差就是本站自動化的笑點。

> 本產生器**只模仿句式結構**，不對任何真實人物作事實指控。見〔[聲明](#-聲明)〕。

### 經典公式

```
讓【對象】找回他失去的【A】
→ 有了 A，自然就會有【B】
→ 而 B 帶來的，正是【C】的根本
→ 就是那麼簡單的道理而已。
```

### 2026 版公式（順起來版）

取自 2026 年 8 月公布的競選標語「台北順起來」：

```
【卡點A】卡、【卡點B】卡，什麼都卡
→ 為什麼卡？因為接點斷了
→ 把斷掉的接點連起來
→ 接起來，就順了。
```

## ✨ 功能

| | |
|---|---|
| 📝 **一鍵產生貼文** | 不用填任何欄位，點一下就產出 100–300 字的完整貼文——含開場、多層遞進、金句收尾、hashtag。 |
| 💬 **產生回覆** | 貼上對方的留言，前端自製的中文斷詞器抽出關鍵詞，生成一篇「回應了但等於沒回應」的回覆。 |
| 🎚 **廢話濃度滑桿** | 低（點到為止）／中（恰到好處的空泛）／高（資訊量趨近於零），控制遞進層數與贅詞密度。 |
| 🧵 **Threads 貼文卡片** | 產出結果模擬 Threads 外觀，另有 5 則串文模式。 |
| ↗ **分享到 Threads** | 一鍵帶文字開啟 Threads 發文視窗。 |
| 🔁 **換一篇 · 📋 複製 · 🕘 紀錄** | 同參數重骰、一鍵複製附字數、最近 5 筆存於 `localStorage`。 |
| 🔧 **進階模式** | 自己填關鍵詞，模板會自動收斂到真的用得到這些詞的那幾則。 |
| 🌙 **深淺色主題 · 📱 手機 RWD** | 375px 實測不破版。 |

## 🚀 使用方式

無 build 步驟、無套件管理、無任何相依套件。

```bash
git clone https://github.com/bounce12340/boyangti-generator.git
cd boyangti-generator
python3 -m http.server 8000     # → http://localhost:8000
```

直接用 `file://` 開啟 `index.html` 也可以——頁面只用 `<script src>`，沒有 ES module 也沒有 `fetch`。

接著：選風格與濃度 → 點「📝 一鍵產生貼文」→ 複製，或切到「💬 產生回覆」貼上對方留言。

## 🏗 架構

五個檔案。`data/corpus.js` 宣告全域 `CORPUS`，**必須**先於 `app.js` 載入——`app.js` 本身不含任何文案，所有使用者看到的字都來自語料庫。

```
index.html          標記與兩個 script 標籤（載入順序有意義）
style.css           :root / [data-theme="dark"] 下的設計 token
app.js              產生引擎、渲染、儲存、主題
data/corpus.js      所有模板與詞庫
data/style-guide.md 風格分析與分級來源清單
```

產生管線：

```
drawVals()   從 CORPUS.words 抽出佔位符的值
pick(pool)   從 CORPUS.styles[風格].templates 挑一則模板
fill()       代入 {placeholder}                        → 本文
compose()    開場白 + 本文 + 填充句（+ 轉折句）+ 收尾，依濃度決定份量
drawTags()   hashtag
```

一個風格是 `{ name, templates }` 加上三個選用旗標：`noOpener`（不加開場白）、`closers`（風格專屬收尾池）、以及 `threadSets`（**取代** `templates`，5 則一組的串文，在 `makePost()` 走另一個分支）。新增風格的 key 也必須加進 `app.js` 的 `STYLE_ORDER`，否則不會渲染分頁。

產生的文字一律以 `textContent` 寫入，絕不用 `innerHTML`——回覆模式會把使用者輸入回填到輸出裡，這條不變式很重要。

開發說明見 [`CLAUDE.md`](CLAUDE.md)。

## 📐 語料編輯規範

[`data/style-guide.md`](data/style-guide.md) 是語料庫背後的分析文件：開場白、轉折詞、口頭禪與遞進結構的類型學，一份標註 **官方／一手／二手／論壇** 的完整 URL 清單，一份誠實標註的未查證項目，以及一份**刻意排除**材料的清單。

其約束規範所有語料修改：

- **只模仿說話風格**——不得出現對任何真實人物的事實指控、人身攻擊或私生活內容。
- 每則模板都要帶來源註解（`〔原站〕` `〔一手〕` `〔二手〕` `〔論壇〕`）。
- 取自新聞的材料先寫進風格指南，再據以衍生模板；經查證後排除的材料要記下排除理由，避免日後又被「重新發現」加回來。
